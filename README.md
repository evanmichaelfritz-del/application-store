# Application Store

Evan Fritz’s master storefront — Expo (React Native + TypeScript) baseball-card gallery. Live showcase, **Copy code**, and **AGENT_PROMPT** on every seeded piece. Not Helix. Not grok.me. Not a transitions.dev recreate.

Adapted from the public transitions.dev Expo gallery (`evanmichaelfritz-del/transitions-dev-expo`). Same card chrome, stages, springs, and Inter / `#fdfdfd` language.

Public repo: [evanmichaelfritz-del/application-store](https://github.com/evanmichaelfritz-del/application-store).

## Add a piece

Continuous-add path (do not invent new card chrome):

1. Live demo in `src/demos/<Name>.tsx` (`Stage` + Reanimated; no CSS `@keyframes` driving the demo).
2. Portable snippet in `src/snippets.ts` keyed by `id`.
3. Motion lock in `src/agentPrompts.ts` (`LOCKS[id]`).
4. Register one object on `TRANSITIONS` in `src/catalog.ts` with `sections` + `categories`.

Empty sections render a dashed add-slot card. New nav rows: append to `NAV_SECTIONS` in `src/sections.ts`.

```

```

## Deploy on Vercel Hobby

This app is a static Expo web export. **Hobby is enough.** `vercel.json` already sets install, build, and `dist`. Production branch is **main**. Public GitHub is the git source — no Origin git link required.

1. Push this repo to GitHub (already public on `main`).
2. In [Vercel](https://vercel.com) → **Add New…** → **Project** → import `evanmichaelfritz-del/application-store`.
3. Hobby plan. Framework **Other**. Confirm (also in `vercel.json`):
   - **Build Command:** `npx setup-skia-web public && npx expo export --platform web`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
   - **Node:** 20+
4. Deploy. The first Hobby deploy gets a `*.vercel.app` URL. Later pushes to `main` redeploy.

Optional CLI (same Hobby project; needs `vercel login` or `VERCEL_TOKEN`):

```bash
npx vercel --yes
npx vercel --prod --yes
```

Local production-shaped check:

```bash
npm run export:web
npx serve dist
```

`public/canvaskit.wasm` is gitignored and regenerated by `postinstall` / the Vercel build so the gooey stage works on web.

## Stack

- Expo SDK 57, React Native 0.86, React 19, TypeScript
- Expo Router
- `react-native-reanimated` 4 + `react-native-worklets`
- `react-native-gesture-handler`
- `react-native-svg`
- `@shopify/react-native-skia` (Gooey metaball; CanvasKit on web)
- Inter via `@expo-google-fonts/inter`
- `expo-clipboard` for Copy code / Copy prompt

Motion is RN-native (`src/motion.ts`). Copy still emits portable CSS for paste-into-web.
